Ngoc OS ✿

Privacy Policy

Effective date: August 13, 2026

Ngoc OS is currently a private personal productivity prototype intended for use by its owner. This policy explains how the prototype may handle data, including data accessed through an optional Pinterest connection.

1. Information handled by Ngoc OS

Ngoc OS may store information that the owner intentionally enters into the dashboard, such as tasks, personal notes, daily activity logs, simple expense or income records, and other personal organizational data.

If the owner connects a Pinterest account, Ngoc OS may request read-only access to account information, Boards, and Pins that the authenticated Pinterest user has explicitly authorized through Pinterest OAuth.

2. How Pinterest data is used

Pinterest data is used only to personalize visual elements of the Ngoc OS dashboard, such as selecting or displaying visual inspiration and wallpapers that match the owner's preferences.

Ngoc OS does not use Pinterest data for advertising, ad targeting, resale, user profiling for third parties, or unrelated commercial purposes.

3. Pinterest permissions

The prototype is designed to request only the permissions needed for its read-only use case, such as boards:read, pins:read, and user_accounts:read.

Ngoc OS does not require permission to create, edit, or delete Pins and does not manage Pinterest advertising campaigns.

4. No automated scraping

Ngoc OS does not scrape Pinterest pages or attempt to access Pinterest content outside the official authorization and API mechanisms made available by Pinterest.

5. Data sharing and sale

Ngoc OS does not sell personal information or Pinterest data. The prototype is not designed to share the owner's personal information or Pinterest data with advertisers or unrelated third parties.

6. Data storage and security

The production version of Ngoc OS will store authentication credentials, tokens, and other sensitive configuration on the server side rather than exposing them in client-side code. Reasonable technical safeguards will be used to limit access to the owner and to services required to operate the prototype.

7. Revoking Pinterest access

The owner can revoke the application's access from Pinterest account settings or by disconnecting Pinterest from Ngoc OS when that feature is available. After access is revoked, Ngoc OS will no longer be able to retrieve new Pinterest data using that authorization.

8. Data deletion

Because Ngoc OS is currently a private prototype, requests to remove stored prototype data can be handled directly by the owner through the underlying storage used by the application. Pinterest access tokens can be deleted or invalidated when the Pinterest connection is removed.

9. Children's data

Ngoc OS is not designed for children and does not intentionally collect information from children.

10. Changes to this policy

This policy may be updated as the prototype changes. Material changes will be reflected on this page with an updated effective date.

11. Contact

For privacy questions about this prototype, contact the repository owner through the public project repository at github.com/ngocbabby/ngoc-os.
